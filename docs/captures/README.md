# Captures d'ecran

Ce dossier accueille les captures utilisees dans le README, la fiche technique PDF et la presentation du projet.

## Captures recommandees

1. `01-accueil.png` - page d'accueil publique.
2. `02-tableau-de-bord.png` - espace etudiant.
3. `03-admin.png` - tableau de bord d'administration.
4. `04-programme.png` - programme et inscription a un evenement.
5. `05-tresorerie.png` - tresorerie et recu PDF.
6. `06-communication.png` - canaux de discussion.
7. `07-mobile.png` - affichage mobile.

## Bonnes pratiques

- Utiliser des donnees de demonstration, jamais des donnees etudiantes reelles.
- Masquer les emails, numeros de telephone, matricules et visages si necessaire.
- Preferer un format PNG, une largeur de 1440 px pour le bureau et 390 px pour le mobile.
- Conserver des noms de fichiers simples et numerotes.
